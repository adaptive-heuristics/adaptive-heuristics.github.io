# Online Appendix

Supplementary material for the manuscript "Adaptive Heuristics in Stock Selection," prepared for anonymous peer review.

- Website: https://ai-interview-stock.github.io/
- Full appendix (PDF): https://ai-interview-stock.github.io/OA.pdf

The site in `docs/` is generated from the manuscript sources by `tools/oa.py`: tables are converted from their
LaTeX sources and figures from the original figure files, so the website and the PDF always show the same
numbers. Run `python tools/oa.py --help` for the commands.
