Table F3: Follow-Up Survey Demographics

This table shows descriptive statistics for the 600 investors who completed the follow-up survey. The first row covers the full follow-up survey sample. The remaining rows group these investors by gender, age, education, investable assets, self-reported investment knowledge, and self-reported risk attitude, each of which we elicit in the background survey. We leave the percentage columns blank for groups with no investors. Columns (1) and (2) report the number of investors in each group and that number as a percentage of the sample. Columns (3) through (6) report the percentage of investors within each group who report owning individual stocks, mutual funds or exchange-traded funds, derivatives, and cryptocurrencies, respectively. Column (3) equals 100% by construction, because we filter out investors who do not own any individual stocks before the interview stage.
