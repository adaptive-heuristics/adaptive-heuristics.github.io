Table F11

Heuristic Adoption and Historical Effectiveness: By Objective

This table repeats the reduced-form adoption analysis of Table F10 separately for each financial objective. In each column, we regress D(Adoption) on the interaction between the importance rating of the objective, standardized within investor across the three financial objectives, and the historical effectiveness of the heuristic for that objective in the country of the investor. Each column uses the full grid of the 600 follow-up respondents and the seven covered heuristics for the corresponding objective (4,200 observations). Investor FE and Country × Heuristic FE refer to the corresponding fixed effects. We cluster standard errors at the country level and report them in parentheses. The wild-cluster bootstrap is not computable under these fixed effects, so we base the stars on the country-clustered standard errors. The interactions for upside and stability remain significant at the 10% level when we instead cluster standard errors at the investor level. Statistical significance at the 10%, 5%, and 1% levels is denoted by *, **, and ***, respectively.
