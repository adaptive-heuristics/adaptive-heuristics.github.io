Table E1: Mapping Heuristics to Firm Characteristics: LLM Consensus

This table reports the consensus mapping of each model–prompt setup. For each heuristic, the consensus keeps the characteristics that the responses select most often, and the number it keeps is the most common number of characteristics per response. Panel A uses GPT-6.1 Sol and Panel B uses Claude Sonnet 5.5. Prompt A supplies no investor background, and Prompt B adds the background of an interviewed investor who adopts the heuristic. Bold variable names mark characteristics that our mapping assigns to the same heuristic, and a blank cell means that the consensus for that prompt does not include the characteristic. As in Table 5 of the main paper, a positive (negative) sign means that we take the heuristic to favor stocks with high (low) values of the characteristic. Within each heuristic, the bold characteristics come first, in the order of that table, and the others follow in alphabetical order of their variable names. We give the models definitions based on the JKP documentation of factors, so their wording can differ from that in this table, which is polished for readability.
