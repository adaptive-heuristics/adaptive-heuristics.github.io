C.2 Bottom-Up Mechanism Generation

The key elements of the prompt used for bottom-up mechanism generation (Section 3.3 of the main paper) are as follows:

  1. 1.
    Core Objective. The goal is to identify the key causal mechanisms that drive the stock-purchase decisions of individual investors in the 1,540 investor-level DAGs and to synthesize a general statement describing each mechanism.
  2. 2.
    Input. The model receives as input a JSON file containing the 1,540 investor DAGs constructed in the argument map construction stage (Online Appendix C.1).
  3. 3.

    Method. We provide a set of instructions as follows:

    1. (a)
      Parse all DAGs: Read all 1,540 DAGs, extract all directed paths leading to the buy-stock action, and identify recurring pathway patterns.
    2. (b)
      Identify mechanisms: Synthesize candidate mechanisms from the recurring pathways, focusing on decision rules, initiating drivers, and accelerators or moderators. The instruction emphasizes identifying true causal drivers. To maintain generality, we instruct the model to avoid splitting mechanisms based on minor variations when the core causal structure is identical, and to exclude highly idiosyncratic patterns that appear only in a small number of DAGs. To prevent hallucination, the model must tie each mechanism to the raw evidence by listing representative paths with exact node names and the IDs of supporting investors.
    3. (c)
      Write statements: Formulate a theory-like statement for each identified mechanism.
